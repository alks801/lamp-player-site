# Lamp Player: сайт

Сайт приложения [Lamp Player](https://github.com/alks801/lamp-player), публикуется через GitHub Pages из ветки `main`:

- https://alks801.github.io/lamp-player-site/ — главная (английский)
- https://alks801.github.io/lamp-player-site/ru.html — главная (русский)
- https://alks801.github.io/lamp-player-site/privacy.html — политика конфиденциальности, ссылка для Google Play
- https://alks801.github.io/lamp-player-site/thanks.html — переадресация на страницу благодарности автору. Клавиша «Сказать спасибо» в приложении открывает именно этот адрес, поэтому его нельзя менять или удалять. Если страница оплаты переедет, новый адрес вписывается в `thanks.html` (в трёх местах), а приложение пересобирать не нужно

Обычный статический HTML без сборки и внешних шрифтов. На главных страницах подключается Яндекс Метрика; на странице политики конфиденциальности скриптов и счётчиков нет. Аналитика сайта не относится к приложению: в самом Lamp Player аналитики нет.

## Аналитика

Счётчик [114730021](https://metrika.yandex.ru/dashboard?id=114730021) настроен в `analytics.js` для `https://alks801.github.io/lamp-player-site/`. Локальные страницы (`file:`, `localhost`, `127.0.0.1`, `[::1]`) не отправляют статистику.

1. В настройках счётчика добавить цель типа «JavaScript-событие» с идентификатором `download_apk`.
2. После публикации открыть обе главные страницы и нажать «Скачать APK». Проверить посещения и достижение цели в Метрике; для отладки можно открыть страницу с `?_ym_debug=2`.

Счётчик учитывает просмотры, переходы по ссылкам, карту кликов и показатель отказов. Вебвизор отключён. Цель `download_apk` отправляется при нажатии на ссылку скачивания, в том числе с клавиатуры и средней кнопкой мыши. Параметры: `language` (`en`/`ru`), `version` (из URL релиза), `platform` (`android`), `file_name`. Это число нажатий, а не подтверждение завершённого скачивания или установки. Ссылка работает и при блокировке Метрики или отключённом JavaScript.

Кнопка «Скачать APK» на главных страницах ведёт на файл в [релизах этого репозитория](https://github.com/alks801/lamp-player-site/releases): так 30-мегабайтные сборки не раздувают историю git. Для новой версии: создать здесь релиз `vX.Y.Z` с файлом `LampPlayer-X.Y.Z-arm64.apk`, затем поправить ссылку и номер версии в `index.html` и `ru.html`.

`privacy.html` сделан из `docs/PRIVACY.md` репозитория приложения. Картинки в `img/` взяты из `docs/store/` там же и уменьшены.
